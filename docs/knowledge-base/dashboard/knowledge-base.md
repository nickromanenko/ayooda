# Use the dashboard Knowledge Base

The Knowledge Base contains product documentation for every section of the Ayooda dashboard. Articles describe the current interface, permissions, side effects, safe operating guidance, and troubleshooting steps.

## Find the right article

Use **Search all help** to search article titles, summaries, categories, dashboard routes, keywords, and full article text. Category filters narrow the results to areas such as Agents, Conversations, Operations, Analytics, Security, and Workspace. Clear the query and select **All** if an expected result is hidden by a filter.

Select an article in the results to read it. On a small screen, **All articles** returns to the search list. Related articles at the end of a guide connect configuration that commonly works together.

## Get help for the current page

The dashboard navigation shows **Help for this page** when a published article matches the page you are viewing. Select it to open the corresponding guide directly. Agent identifiers are normalized, so every agent's Knowledge page uses the same Agent knowledge article, for example.

Use **Copy link** to share the selected article with another signed-in teammate. Knowledge Base links require access to the Ayooda dashboard; they are not public customer documentation.

## Article accuracy

The articles are published from version-controlled Markdown into Ayooda's dedicated knowledge-base collection. If an article and the interface disagree, treat the interface and your saved configuration cautiously and report the discrepancy so the source article can be corrected and republished.

This product Knowledge Base is separate from each agent's customer-facing Knowledge tab. Reading or publishing an Ayooda help article does not add it to your own agent's knowledge sources.
