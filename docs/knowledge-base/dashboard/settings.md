# Profile and workspace settings

Settings contains account identity and workspace-wide naming. Agent-specific behavior belongs on the corresponding agent page.

## Profile

**Display name** is the human-readable name shown to teammates in workspace controls such as assignments and access lists. Update it and choose **Save changes**. A blank display name cannot be saved.

**Email** identifies the signed-in account and is read-only on this page. Changing authentication email is not part of dashboard Settings.

## Workspace

**Workspace name** is the shared organization or team name. Changing it does not rename agents, alter customer-facing widget copy, or change channel sender identities. Those values are configured on each agent's Info or Deploy page.

Save Profile and Workspace changes independently. The button stays inactive when there are no changes and confirms when a save completes. If Settings fails to load, the page does not overwrite stored values; use **Retry** before editing.

For other changes:

- use **Team** for membership and invitations;
- use **Billing** for subscription and payment management;
- use an agent's **Info** page for its name, photo, instructions, and model;
- use an agent's **Deploy** page for customer-facing channel and widget settings;
- use an agent's **Security** page for credentials and member access.
