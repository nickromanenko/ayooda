Ayooda Widget — Test Harness

Loads the widget so you can test the chat bubble against a running API. The bubble appears in whichever corner the agent’s Deploy tab is set to, once a valid channel ID is set.

Enter a Channel ID (Dashboard → Agents → your agent → Deploy) and click Load widget. You can also pass them in the URL: test.html?agent=<channelId>&api=http://localhost:3001. Reload the page to swap channels (the widget only loads once per page).
